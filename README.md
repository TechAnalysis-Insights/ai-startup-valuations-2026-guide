## What actually matters when you're evaluating this list

- **Infrastructure and data companies outvalue the model labs.** Databricks and Scale AI combined are worth more than xAI — the market is pricing the picks-and-shovels layer higher than any single frontier model, because every lab still needs clean data and evaluation infrastructure regardless of which model wins.
- **Vertical AI with regulatory complexity commands real premiums.** Abridge (healthcare), Harvey (legal), Socure (identity/compliance), and Shield AI (defense) are all built around domains where a generic LLM wrapper fails on accuracy or compliance — the valuation reflects the cost of getting those details right, not just model quality.
- **"AI startup" increasingly means "AI-native rebuild of an existing category."** UiPath rebuilt RPA around agentic automation; Glean rebuilt enterprise search around retrieval and assistants; Cyera rebuilt data security posture management around protecting AI systems specifically. None of these are net-new categories — they're incumbents or near-incumbents re-architected for the AI era.
- **Hardware is still a small slice of this list.** Graphcore's $222M valuation versus the software plays above it is a reminder that AI-specific silicon remains a much harder, more capital-intensive bet than software built on top of existing GPU infrastructure.
